Do you supply EN 10204 3.1 MTC and third-party witness inspection?

Every valve body and pressure-containing component carries cast/stamped heat numbers traceable to EN 10204 3.1 Mill Test Certificates. We routinely coordinate SGS, TUV, BV, and Lloyd's 3.2 witness testing.

Can valves be supplied with pneumatic, electric, or hydraulic actuation?

Yes. All quarter-turn and multi-turn valves feature ISO 5211 direct-mount pads and can be factory-assembled and bench-calibrated with Rotork, AUMA, Bettis, or OEM scotch-yoke actuators.

How quickly do we receive GA drawings and formal BOM pricing?

Standard inquiries receive itemized FOB/CIF pricing and 2D PDF / 3D STEP general arrangement drawings within 24 business hours.

WordPress + GeneratePress + GenerateBlocks + ACF Pro + Rank Math Blueprint

Exact lightweight B2B foreign-trade architecture (0 jQuery, 0 Elementor bloat, 95–99 Mobile PageSpeed): 

1. Theme & Block Layer (GeneratePress Premium + GenerateBlocks Pro)
   - GP Elements `Block - Content Template`: Custom Single `product_valve` & Archive `valve_category` templates
   - GP Elements `Block - Hook (after_header / before_footer)`: Sticky Engineering RFQ bar & Certification trust strip
   - GB Pro `Query Loop` + Dynamic Data tags bound directly to ACF custom fields (only 4 core semantic classes)

2. Custom Post Types & ACF Pro Field Groups
   - CPT `product_valve` + Taxonomies `valve_category`, `application_sector`, `certification_standard`
   - ACF Field Group `group_valve_engineering_specs`:
     • `sku_code` (Text)                • `nominal_diameter` (Text: DN15–DN1200 / 1/2"–48")
     • `pressure_rating` (Select/Text)  • `body_material` (Checkbox: WCB, LCB, CF8M, Duplex 2205)
     • `design_standard` (Text: API 6D) • `end_connection` (Text: RF Flanged / BW / RTJ)
     • `datasheet_pdf` (File URL)       • `related_cases` (Bidirectional Relationship to `project_case` CPT)

3. Rank Math Pro / Custom Filter Dynamic SEO & JSON-LD Schema
   - Dynamic Title Variable: `%title% | %cf_design_standard% %cf_body_material% Manufacturer`
   - Auto-injected `Product` + `Organization` + `FAQPage` Schema via `rank_math/json_ld` PHP filter reading ACF specs
